# Definition of done

- [ ] The owning module and changed callers are correct.
- [ ] No unrelated changes, duplicate shared UI, secrets, or generated output are included.
- [ ] Relevant behavior and failure paths are covered by meaningful tests.
- [ ] Applicable Pint, Blade, Vite, and changed-file checks pass.
- [ ] Database changes have a safe migration, rollback, and seed/deployment path.
- [ ] UI changes preserve accessibility, responsive behavior, and the supplied orange banner.
- [ ] The final report distinguishes verified behavior from untested external systems.
